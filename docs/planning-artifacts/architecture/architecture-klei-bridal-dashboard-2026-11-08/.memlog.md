- (decision) Process boundary: ONE deployable Spring Boot app, TWO Tomcat connectors (8080 API, 8081 Auth Web). Port-guard filter returns 404 for API paths on 8081 and Auth Web paths on 8080. Rejected: two apps (second image, duplicated config) until Auth Web needs independent scaling.
- (decision) DEK model: one tenant DEK (single Workspace) in data_key table wrapped by KEK; each MinIO object gets its own DEK wrapped by KEK and stored on its DB row. Column ciphertext embeds dek_id; every wrapped DEK carries kek_version. KEK rotation = re-wrap DEK rows only, no data re-encryption. Reason: per-record DEK costs a wrapped key per field per row at 100k photos for no gain with one tenant.
- (decision) AAD needs row id; a plain JPA AttributeConverter cannot see it. Mechanism: Hibernate PreInsert/PreUpdate/PostLoad listener in crypto module driven by @Encrypted on entity fields, mapped to bytea *_ct columns. Deviates from NFR wording 'AttributeConverter or Exposed column type' (intent preserved: transparent, one place). Story 1.3 proves it; fallback documented in ADR.
- (decision) Ordering without timestamps: plaintext monotonic bigint seq columns (gown, inquiry activity, audit, notification, message) give keyset paging and newest-first. Reveals order only, not time. Needs ADR + user awareness (NFR-1 allows only UUID keys, schema tables, envelope fields unencrypted).
- (decision) Date filter: day-bucket blind index (HMAC over table|column|yyyy-MM-dd); Last 7/30/90 = IN list of up to 90 hashes. Leaks same-day grouping only.
- (decision) Search: word-level blind index tables gown_term and inquiry_term (term_bidx, entity id). Whole-word, case-insensitive, AND of query words. Leaks term frequency and co-occurrence to a DB reader; key not in DB so no offline dictionary attack.
- (decision) Embeddings stored encrypted per Photo. MVP compares only inside one Upload Batch (max 200 vectors) in memory. No catalog-wide vector search in MVP (Deferred); Suggest gowns uses chat model over Gallery text.
- (decision) Desktop: Rust core is the only network client. Tokens in keychain never reach the webview. Webview CSP forbids network; React calls Rust command api_request. Zip assembled in Rust.
- (decision) API: code-first springdoc, openapi.json snapshot committed at docs/api/openapi.json with drift test; TS types via openapi-typescript. Errors RFC 9457 problem+json with stable code and correlationId, no echoed values. Keyset paging by seq.
- (decision) Objects: AWS SDK v2 S3 client (works with any S3 server). Single-shot AES-256-GCM per object (25 MB cap), AAD=bucket+key, per-object DEK. Thumbnails (480px JPEG) generated at upload and stored as separate encrypted objects so Gallery never decrypts originals.
- (decision) Leak guard: schema test fails the build if any column outside the allowlist (uuid id/fk, seq, *_ct, *_bidx, flyway tables) exists, so a new plaintext column cannot ship unnoticed.
- (decision) Maven Wrapper (mvnw, Maven 3.9.x) so developer needs no Maven install. Rust via rustup stable 1.99.1. JDK 25 Temurin via toolchain.
