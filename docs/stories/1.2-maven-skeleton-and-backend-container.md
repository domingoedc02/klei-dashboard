# Story 1.2: Maven multi-module skeleton and backend container

As a developer,
I want a building Spring Boot app in modules `crypto`, `core`, `app` with two connectors, health endpoints and CI rules, running in compose,
So that every later story adds code to a structure that already enforces the architecture.

**Assumptions**
- Versions come from the spine Stack table: Spring Boot 4.1.2, Kotlin 2.3.21, JDK 25, Testcontainers 2.0.5, ArchUnit 1.5.1. Boot-managed pins are not overridden.
- No domain code yet. The only database object is Flyway's own table plus a `V1__baseline.sql` that creates nothing else.

**Acceptance Criteria**

**Given** a machine with only JDK 25 and Docker
**When** `cd backend && ./mvnw verify` runs
**Then** modules build in order `crypto`, `core`, `app` and all tests pass.

**Given** the ArchUnit tests
**When** a class in `core` imports a class from `app`, or any class outside `crypto` imports `javax.crypto`, `java.security.MessageDigest` or `java.security.SecureRandom`
**Then** the build fails with the rule name (AD-2).

**Given** the running app
**When** `GET :8080/health` and `GET :8081/health` are called
**Then** both answer 200 `{"status":"up"}`; `GET /health/ready` answers 200 only when PostgreSQL and the bucket are reachable and 503 `unavailable` otherwise.

**Given** the port guard (AD-1)
**When** `GET :8081/api/v1/…` or `GET :8080/login` is called
**Then** the response is 404 problem+json, so each surface is unreachable on the other port.

**Given** any error
**When** the response is produced
**Then** it is `application/problem+json` with `type`, `title`, `status`, `code`, `correlationId`, and no stack trace or message text (AD-11, AD-14).

**Given** a request
**When** it is logged
**Then** the log line holds method, status, duration and `correlationId` only, never a path parameter value, query string or body.

**Given** `infra/Dockerfile` and the `backend` compose service
**When** `docker compose -f infra/docker-compose.yml --profile dev up -d --wait` runs
**Then** the backend container (non-root, read-only root fs, `/tmp` tmpfs, 1 GB limit, `-XX:+ExitOnOutOfMemoryError`) is healthy after postgres and objectstore, Flyway ran `V1`, and the bucket exists (created at startup if missing).

**Given** a missing or malformed required `KLEI_*` variable
**When** the container starts
**Then** the boot stops with a code naming the variable, never its value (startup checks 1 and 2, architecture §9.2).

**Tasks**
- Parent `pom.xml` with BOM, Kotlin and JDK 25 toolchain; `mvnw`; modules; `app` main class with two connectors and the port guard filter.
- `HealthController`, `ReadinessCheck` (DB, S3 `HeadBucket`), `ProblemAdvice`, `CorrelationIdFilter`, log pattern.
- `ObjectStorePort` with AWS SDK v2 adapter (path-style) and bucket creation at startup.
- Flyway wiring and `V1__baseline.sql`.
- ArchUnit tests: module arrows, crypto confinement. Stub of the endpoint-annotation rule (AD-9) that passes while no endpoints exist besides health (`@PermitAll`).
- `infra/Dockerfile`, add `backend` to compose, extend `smoke.sh` with health checks and the port-guard checks.
- `infra/ci` backend pipeline definition (`./mvnw verify`).

**Checks**
- `cd backend && ./mvnw verify`
- `docker compose -f infra/docker-compose.yml --profile dev up -d --wait && infra/ci/smoke.sh`
- Desktop tests: not applicable yet.
- NFR-1: a log-capture test asserts the log holds no request path values; no business table exists.

## Dev and QA record (2026-11-08)

**Result:** all 8 criteria pass.

- `cd backend && ./mvnw verify` on JDK 25: crypto, core, app build in order; 9 unit tests (ArchUnit, startup checks) and 8 integration tests (Testcontainers PostgreSQL 18.6) pass.
- ArchUnit: `core` must not import `app`; JCA types only in `crypto` (negative test on `co.klei.fixture.Violator` proves the rule fires and names itself); AD-9 endpoint rule passes on health `@PermitAll` and fails on an unannotated mapping.
- Health on both ports, `/health/ready` 200 or 503 `unavailable`, port guard 404 problem+json both ways, unhandled exception returns a bare 500 with no message, access log holds method, status, duration, `correlationId` only (sentinel path and query absent).
- Compose: backend healthy after postgres and objectstore; non-root user 10001, read-only root fs, `/tmp` tmpfs, 1 GB limit, `-XX:+ExitOnOutOfMemoryError`; Flyway V1 applied; bucket created at startup. `infra/ci/smoke.sh` passes (12 checks).
- Missing `KLEI_DB_USER`: boot exits with `code=missing_variable variables=KLEI_DB_USER`; value never printed.
- No secret value from `infra/.env` found elsewhere in the repo.

**Deviations and shortcuts**
- Healthcheck uses bash `/dev/tcp` because `eclipse-temurin:25-jre` has no curl or wget.
- `StartupChecks` checks base64 and size of keys only; parsing the Ed25519 `KLEI_JWT_KEY` waits for Story 1.5. Checks 3 to 7 of architecture §9.2 arrive with Stories 1.3 and 1.4.
- ArchUnit rule `crypto-must-not-import-core-or-app` runs with `allowEmptyShould` until Story 1.3 adds classes to `crypto`.
- CI: `infra/ci/backend.sh` and `.github/workflows/backend.yml`. Not run on a hosted runner (no git repository yet).
- Maven needs JDK 25 locally; default `java` here is 27.
