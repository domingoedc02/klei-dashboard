# Story 11.9: Customer profile matches the prototype

As a Staff member,
I want the profile page of a person who wrote in to look and read like the approved prototype,
So that I find the same facts in the same places.

**Assumptions**
- User decision (2026-11-10): the UI says "Customer". The code, API, database and OpenAPI keep `client`. This reverses PRD glossary line 92 ("customer" means Client); the glossary entry is rewritten in this story.
- The Edit button and its dialog (`EditClient.tsx`, Story 7.4) are not in the prototype. They stay, placed next to **Email {First}**. The "Heard about us" values keep the product list (`SOURCES`: Website, Instagram, Referral, Event, Other); the prototype's sample data (Google search, Pinterest, Friend referral) is demo data.
- Missing values keep the desktop pattern: "—" with a screen-reader "Not set".
- First task: confirm the **verify** row (`.cprof` two-column widths `380px 1fr`) against `ClientProfile.tsx` and `prototype/v0.1.0/js/inquiries.js` lines 37-47.

**Acceptance Criteria**

**Given** the profile page
**When** it renders
**Then** the breadcrumb reads "Inquiries › {name}" with a chevron icon (not " / ") and `aria-current="page"` on the name; the header shows a 72 px avatar, the name as h1, "{city} · Wedding {date}", **Email {First name}** (a `mailto:` button) and **Edit**.

**Given** the "Personal details" card
**When** it renders
**Then** it lists, in a 96 px label column: Full name, Email, Phone, City, Wedding date, Heard about us, Customer since, Notes; a missing value shows "—".

**Given** the inquiries card
**When** it renders
**Then** the heading reads "All inquiries ({n})" and each row shows subject, a preview, time and the status pill, and opens the thread.

**Given** an id that no longer exists
**When** the page loads
**Then** the h1 reads "Customer not found" under the same breadcrumb.

**Given** the UI copy
**When** searched
**Then** no user-visible string in `desktop/src` says "Client" (tests, code identifiers and the API are exempt): "Customer since", "Unknown customer", "Customer updated" and the Edit dialog title "Edit customer".

**Given** the PRD glossary
**When** this story is done
**Then** line 92 defines **Customer** as the UI word for the person who sent Inquiries, and notes that code and API say `client`.

**Given** the axe run
**When** it covers the profile
**Then** no serious or critical issues.
