# Story 5.2: Gown viewer

As any signed-in User,
I want to open a gown and flip through its photos with its details beside them,
So that I can inspect it and copy its description.

**Assumptions**
- Photos are fetched one at a time through `klei-img://` (full size on demand, thumbnails for the strip).
- Description copy: the webview writes the clipboard with `navigator.clipboard.writeText` (no new Rust command; the set stays closed per AD-10). If the webview API is blocked by the platform, OPEN QUESTION: allow the Tauri clipboard plugin as a documented exception. Default: webview API.
- Edit, Download and Delete buttons are added by 5.3 to 5.5; this story ships the page without those buttons (rule from 4.2: a control ships only with its endpoint).
- `GET /gowns/{id}` returns 404 for an unknown id.

**Acceptance Criteria**

**Given** `GET /gowns/{id}`
**When** called with `PERM_VIEW_GALLERY` (403 `forbidden` without it; the photo reads need it too)
**Then** it returns name, attributes by type, Photo ids in order with their `size`, Photo count, date added, confidence band and percent, description and `version`.

**Given** `GET /gowns/{id}/photos/{pid}?size=thumb|full`
**When** the Photo belongs to the Gown
**Then** the object is decrypted and streamed with fixed Content-Type, `nosniff`, `Cache-Control: no-store`; a Photo of another Gown returns 404; tampering returns 500 `crypto_failure`.

**Given** G2
**When** it renders
**Then** the left stage shows the current photo with previous/next buttons, "2 of 7" and a thumbnail strip; arrow keys move; the details pane (360) shows the name, attribute groups as neutral tags, Photo count, date added, confidence pill, description and **Copy description**.

**Given** **Copy description**
**When** pressed
**Then** the text goes to the clipboard and the toast "Description copied" shows.

**Given** the breadcrumb "Gallery / {name}"
**When** pressed
**Then** Gallery restores its filters.

**Given** loading and failure
**When** they occur
**Then** the stage is a grey tile with skeleton details; a failed Photo shows "This photo couldn't be loaded." with Retry; a failed Gown shows an error block with Retry.

**Given** the leak suite
**When** extended
**Then** reads of Photos leave no cached plaintext on disk (Rust test, same as 4.2) and responses carry the fixed headers.

**Tasks**
- Backend: `GownDetailController`, `PhotoReadController` extension for Gown Photos, tests.
- Desktop: viewer route, stage, strip, details, clipboard, tests, axe.

**Checks**
- `cd backend && ./mvnw verify`
- `cd desktop && npm test && (cd src-tauri && cargo test)`
- `docker compose -f infra/docker-compose.yml --profile dev up -d --wait && infra/ci/smoke.sh` (extend: read a Gown, fetch one thumbnail, assert headers).

## Dev record

**Assumptions**
- Reads need `PERM_VIEW_GALLERY` only. `GET /api/v1/gowns/{id}` returns name, description, attributes grouped by type (only types that have a value, values sorted), Photo ids with byte size in upload order, `photoCount`, `addedAt`, `confidence` percent, `band` (same cut-offs as review: 90 high, 80 medium, else low) and `version` (5.3 will send it as `If-Match`). Unknown id is 404, malformed id is 400. `[ASSUMPTION]`
- The viewer reuses the 5.1 photo read: thumbnails in the strip, `?size=full` on the stage. A Photo on another Gown is 404; a swapped object is 500 `crypto_failure`.
- OPEN QUESTION default: Copy description uses `navigator.clipboard.writeText` in the webview. A refusal shows "Couldn't copy the description." Not tried on the three real webviews.
- Route is `#/gallery/{gownId}`. Breadcrumb "Gallery" goes to `#/gallery`; the Gallery restores filters and loaded pages from `memory.ts`.
- No Edit, Download or Delete buttons yet (5.3, 5.4, 5.5).

**Done**
- Backend: `GownQueryService.detail`, `GownDetail`/`GownPhoto`/`GownTags`, `GET /api/v1/gowns/{id}` in `GownQueryController`. `openapi.json` and `schema.d.ts` regenerated.
- Desktop: `gallery/Viewer.tsx` (stage, Previous/Next, "2 of 7", thumbnail strip, arrow keys, 360px details pane with neutral tags, counts, date, confidence pill, description, Copy description with toast "Description copied", grey tile and skeleton while loading, "This photo couldn't be loaded." with Retry, error block with Retry, "This gown no longer exists", no-photos and no-description states). `shell/route.ts` gained `useRouteArg()`; `Shell.tsx` shows the Viewer for `#/gallery/{id}`; Gallery card names link to it. Viewer CSS appended to `styles.css`.
