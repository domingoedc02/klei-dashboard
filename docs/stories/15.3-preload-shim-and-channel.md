# Story 15.3: Preload shim and Channel compatibility

As a developer, I want the original renderer's `invoke` and `Channel` calls to reach Electron main through nine named, typed preload methods, so that `desktop/src/bridge.ts` runs unchanged and no generic IPC reaches the page.

**Assumptions**
- The route chosen in 14.4 is used. This story is written for Option B (alias module `electron/src/renderer-compat/core.ts` calling named preload methods). Option A is allowed only under the owner-approved AD-24 exception, after 14.4 records why B failed.
- Preload exposes one object through `contextBridge.exposeInMainWorld('kleiBridge', …)` with exactly nine methods: `apiRequest`, `signIn`, `signOut`, `uploadFiles`, `exportGowns`, `checkUpdate`, `installUpdate`, `setDirty`, `sessionOnly`. No `ipcRenderer`, `require`, `send` or generic `invoke` is exposed.
- Channel contract (from the original library and `tauri-shim.mjs`): events reach the page callback as `{ index, message }` with strictly increasing `index`, then one `{ end: true, index }`. The alias module's `Channel` class keeps `onmessage` and hands the named method a plain callback.
- Preload to main uses the single `klei:invoke` channel (15.4) with a fixed command name set by the preload method, never by the page.

**Acceptance Criteria**

**Given** the original `bridge.ts` calls `invoke('upload_files', { kind, targetId, onEvent: channel })`
**When** the alias module handles it
**Then** `uploadFiles` is called with `kind`, `targetId` and a callback; each event main emits reaches `channel.onmessage` as `{ index, message }` in strictly increasing `index`, followed by exactly one `{ end: true, index }`.

**Given** a command rejects
**When** the renderer awaits it
**Then** it receives a plain object `{ kind, message }` with `kind` one of the twelve `ErrorKind` values in `desktop/src/bridge.ts`, never an `Error` with stack, never a path, token or response body.

**Given** `kleiBridge`
**When** its keys are listed from the page
**Then** there are exactly the nine above; any other property is undefined; a page script cannot reach `ipcRenderer`, `process`, `require` or a function that accepts a channel or command name.

**Given** an argument with extra keys, a wrong type, an oversized array or string
**When** preload or main receives it
**Then** it fails `bad_request` before any native work, and a test proves no handler ran.

**Given** a callback is released (command end, page reload)
**When** later events for it arrive
**Then** they are dropped, the callback table has no leak, and ids are never reused within a window's life.

**Given** the page reloads or the window closes during an upload or export
**When** main sees the sender gone
**Then** it cancels exactly as `cancel` would (the export partial file is removed) and releases the single-run lock.

**Given** the preload source
**When** scanned
**Then** it imports only `electron` (`contextBridge`, `ipcRenderer`, `webUtils`) and local types.

**Tasks**
- `electron/src/preload/bridge.ts`: the nine methods, callback table, `ipcRenderer.invoke('klei:invoke', …)`.
- `electron/src/preload/index.ts`: entry, sandbox-compatible, bundled to one file by the Electron build.
- `electron/src/renderer-compat/core.ts`: alias target from 14.4; `Channel` class; command-to-method map.
- `electron/src/shared/commands.ts`: the closed list and argument validators shared with main (15.4).
- `electron/src/shared/events.ts`: event types, checked by a test against `desktop/src/bridge.ts` text.
- `electron/test/preload-bridge.test.ts`: the contract tests above with a fake `ipcRenderer`.
- `electron/test/types-match.test.ts`: read `desktop/src/bridge.ts` and assert the `ErrorKind` list, `UploadKind` list and event shapes equal the shared types.

**Dev notes**
- Reference only: `desktop/src/bridge.ts`, `desktop/scripts/shots/tauri-shim.mjs`, `desktop/src-tauri/tests/contract.rs`.
- Limits: use the limits Rust already enforces (key length 128 bytes, path rules in 16.1). Where Rust has none (`ids` count, `targetId` length), set the smallest bound that keeps the original screens working and record it here when 17.4 and 17.1 are written.
- Electron-only copy changes (for example the 18.3 "Download update" wording) go in `electron/src/renderer-compat/`, never in `desktop/src`.

**Testing**
- Run `electron/test/preload-bridge.test.ts` and `types-match.test.ts`; run the Channel round trip in a real Electron window in CI (19.2).

**Prototype unchanged check**
- Require the 14.1 gate. Run the baseline harness on the Electron renderer for the upload and gallery screens at 1440×900 and compare with the baseline capture; zero geometry findings.
- `desktop/src/bridge.ts` is read, never edited.
