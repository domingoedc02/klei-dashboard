# Story 17.4: Gown archive export

As a Staff member, I want to save selected Gowns and their photos as a ZIP archive, so that the requested export is written only to a location I choose.

**Assumptions**
- ZIP dependency is selected and version-verified in 14.3; Electron main owns manifest requests, photo fetching, save dialog, archive writing and cancellation.
- No decrypted photo data or partial archive persists after a failed or cancelled run; successful output is written only to the chosen destination.

**Acceptance Criteria**

**Given** `export_gowns('start', ids)` with an empty ID list
**When** validation runs
**Then** it rejects as `bad_request` with `nothing to download`; unknown kinds reject as `bad_request` with `unknown download kind`.

**Given** a non-empty ID list
**When** main requests `POST /api/v1/gowns/export` with `{ids}`
**Then** 413 maps to `too_large`, 403 to `no_access`, 422 to `bad_request`, other failures to `failed`; an empty successful manifest fails with `failed` and no save dialog opens.

**Given** a non-empty manifest
**When** the save dialog opens
**Then** its filter is `Zip archive`; one Gown suggests `<clean(name)>.zip`, multiple Gowns suggest `klei-gowns.zip`; dismissal resolves `cancelled:true` and writes no file.

**Given** one or more manifest items
**When** export builds the archive
**Then** photos are fetched serially from `/api/v1/gowns/{gownId}/photos/{photoId}?size=full`; more than one Gown uses one folder per Gown; photos are named `photo-N.jpg|png|webp` and stored uncompressed; `details.txt` is deflated; progress is `{done,total}` counting completed Gowns.

**Given** hostile, long or duplicate Gown names
**When** folder/file names are generated
**Then** `clean()` removes control characters; replaces `/\\:*?\"<>|` with `_`; strips `..`; trims whitespace/dots; limits to 80 characters and 200 UTF-8 bytes; uses `gown` if empty; prefixes Windows reserved names with `_`; duplicate names are suffixed ` (2)`, ` (3)` case-insensitively; as in `export.rs::unique`, the suffix is added after the caps, so a suffixed name can exceed them by the suffix length (parity, not re-capped).

**Given** export is active
**When** another export starts or cancel is invoked
**Then** a second start is rejected; cancel interrupts the run and deletes its partial file; any fetch/archive failure also deletes partial output; the active slot is released after completion.

**Tasks**
- `electron/src/main/export.ts`: port manifest mapping, sanitization/unique names, serial photo fetch, archive layout/compression, progress and partial-file cleanup.
- `electron/src/main/commands.ts`: `start`/`cancel`, `Zip archive` save dialog, safe suggested name and one-export lock.
- `electron/src/preload/bridge.ts`: forward progress and `{gowns,photos,cancelled}` only; never disclose destination or photo bytes.
- `electron/test/export.test.ts`: test status mapping, names/duplicates, archive layout/compression, serial requests, cancellation, error cleanup and concurrency.
