# Story 12.14: Narrow-window and keyboard sweep, baseline sign-off

As the product owner,
I want every screen checked at the smallest and the default window with the keyboard and axe, and the result recorded,
So that Epic 12 closes on evidence, not on a static reading of CSS.

**Assumptions**
- Last story of Epic 12. It changes no feature; it fixes what the sweep finds and deletes what is dead. Findings too big for this story become new stories (not silently expanded).
- Windows: default 1280x800, minimum 1100x700 (`desktop/src-tauri/tauri.conf.json:18-21`). Every `@media (max-width: 900px)` or `960px` rule is dead at this minimum.
- Dead rules to remove if 12.2 has not (`desktop/src/styles.css`): `:262`, `:315`, `:347`, `:482`, `:573`. Re-grep before editing; line numbers drift.
- Tools: the 12.1 harness `node infra/ci/shots.mjs` (all 24 screen keys, both widths, `report.json` checks: overflow, overlap, footer cover, clipped text); desktop axe in vitest (`axe-core` via `axe.run(container, …)`, as in `Shell.test.tsx`; colour-contrast and region rules are disabled there because jsdom has no layout); Auth Web axe with `node infra/ci/axe.mjs` (needs `./mvnw verify` to build `backend/app/target/auth-pages`, and system Chrome).
- Keep the DESIGN.md wins-on-polish list (focus ring `#0063bf`, h1 tracking, stat 32/600, no eyebrow caps, no appointments line, no border plus shadow).
- Undo stays on Review (assumption confirmed in the plan review).

**Acceptance Criteria**

**Given** `node infra/ci/shots.mjs` (the 12.1 screenshot command, no `--only`)
**When** it runs for all screen keys at 1100x700 and 1280x800
**Then** it exits 0 and `desktop/.shots/report.json` has zero failed checks; the run output is pasted in the Dev record.
Test: `infra/ci/shots.test.mjs` (from 12.1) passes under `node --test`.

**Given** `styles.css`
**Then** `grep -nE "@media \(max-width: (7[0-9]{2}|[89][0-9]{2}|10[0-9]{2})px\)" desktop/src/styles.css` returns nothing.
Test: `styles.test.ts` `it('has no max-width media query below the 1100px minimum window')`.

**Given** each screen, tabbing from the top bar
**Then** focus order follows reading order (top bar, then page, then footer/composer), every focused element is fully visible (not under the sticky footer or clipped), the focus ring is `#0063bf` with the 12.2 offset, and Esc closes menus, bell, drawer, hover card and dialogs and returns focus to their opener.
Test: add `src/focusOrder.test.tsx` with one `userEvent.tab()` walk per screen that has more than one control (`Shell`, `Review`, `Gallery`, `Viewer`, `Inquiries`/`Thread`, `Settings`) asserting the expected `getByRole(...)` sequence; extend `Shell.test.tsx` for Esc plus focus return.

**Given** all screens in vitest
**Then** `axe.run` reports zero violations in each existing screen test (contrast is checked by eye in the PNGs), including the states added by Epic 12 (inline Review panel, widget empties, mail cards, Away card).
**Given** the Auth Web pages
**Then** `node infra/ci/axe.mjs` reports zero serious or critical violations.

**Given** the baseline PNGs
**When** each screen key is compared by eye with its prototype screen (12.1 `--prototype` writes `proto-*.png`)
**Then** the comparison result is recorded in `docs/planning-artifacts/ui-fidelity-audit.md` under a new "Sign-off" section: one row per screen key with width 1100 / 1280, verdict (match, accepted deviation with reason, or open finding with a new story id), and the reviewer name and date. Rows for G-01 to G-28 get a final status column.

**Given** accepted deviations collected from 12.8-12.13 (widget empties text-only; Edit gown select + chips; Away on Signature; Back to sign in label only; no verify toggle; Undo kept; Sort inert; Assistant `enterToSend`)
**Then** each is listed in the Sign-off section and in `docs/ux-spec.md`, so the next audit does not re-raise them.

**Tasks**
- Run the sweep, fix findings in the owning component, delete the dead `@media` blocks, add `focusOrder.test.tsx` and the `styles.test.ts` assertion.
- Edit `docs/planning-artifacts/ui-fidelity-audit.md` (Sign-off section, G-row status), `docs/ux-spec.md` (deviation list).
- Write follow-up story files for any open finding (numbered 12.15+), and add them to `docs/epics/epics.md`.
- No backend change, no new dependency.

**Checks**
- `cd desktop && npm test && npm run types:check`
- `node infra/ci/shots.mjs` (all keys) at 1100x700 and 1280x800, then `node --test infra/ci/shots.test.mjs`.
- `./mvnw verify` then `node infra/ci/axe.mjs`.
- Not verified here: screen-reader speech output, Windows/Linux window chrome (macOS WebView only).
