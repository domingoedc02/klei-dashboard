# Story 12.3: Shared components

As a developer,
I want the card, field, skeleton, empty-state art and switch rules defined once,
So that Dashboard, Gallery, Inquiries and Settings stop each carrying their own near-copy.

**Assumptions**
- Audit rows G-21, G-22 (skeleton and empty art), G-23, G-26 (`.set-col`, `.srow`, switch, tabs, empty art size). This story adds the shared CSS and the small shared React pieces; each screen story then uses them. It changes no screen's copy.
- Prototype building blocks: `.card` (1px border, `--radius-lg`, padding `--space-6`, no shadow; `css/base.css:65`), `.card-hover` (shadow only on hover; `css/base.css:67-68`), `.field` (column, gap `--space-2`; label 14/500; `css/base.css:71-72`), `.help` (`css/base.css:84`), `.skel` shimmer (`css/base.css:107-108`), `.btn-ghost`, `.btn-sm`, `.btn-block` (`css/base.css:46-52`), `.chip` (`css/screens.css:141-143`), `.pill-*` (`css/base.css:57-62`).
- App today: no `.card` or `.field` rule exists; forms use `.form` (`desktop/src/styles.css:131-138`), which stacks a bare label above a control; `.skeleton` is a grey block (`styles.css:73-74`); `.empty` art is an `<img width={160}>` in three settings tabs on portrait assets of about 279x640, which renders 366px tall (`AuditTab.tsx:71`, `UsageTab.tsx:49`, `StaffTab.tsx:210`); `.switch` is a bare checkbox; `.tabs` neither wrap nor scroll; `.btn.ghost` exists (`styles.css:609`) but `.btn-sm`/`.btn-block` do not.
- DESIGN.md rule honoured: "never border and shadow together". `.card` is border only; the raised shadow stays on menus, drawer and toasts.
- Components added (CSS under `/* 12.3 */`, class names follow the app's existing style: `btn ghost` not `btn-ghost`):
  - `.card` (border, radius-lg, padding `--space-6`); `.card.warm` (`--color-frame` background).
  - `.field` (`display: grid; gap: var(--space-2)`), `.field > label` 14/500, `.field .help` (muted 12px). `.form` stays for existing screens and is not rewritten.
  - `.btn.sm` (padding 4px 8px, 12px) and `.btn.block` (`width: 100%`).
  - `.empty` art: `.empty img { height: 144px; width: auto; }` and `.empty.compact img { height: 96px }`. Remove the `width={160}` attributes at the three call sites.
  - `.skeleton.row` (40x53 thumb + two lines) and `.skeleton.card` (image + two lines) helpers for 12.8/12.9.
  - `.set-col { max-width: 720px }`, `.srow` (label/help on the left, control on the right, `justify-content: space-between`, `gap: var(--space-4)`, bottom hairline), and `.switch` styled as the prototype pill track (checkbox kept as the real control, `appearance: none`, `:checked` accent, `:focus-visible` ring `var(--color-focus-ring)`).
  - `.tabs { overflow-x: auto; scrollbar-width: none }` and `.tabs button { flex: none }`.
  - `.mono.muted` for the audit IP column.
- `ErrorBlock` Retry already became a `.btn` in 12.2; this story does not touch it.
- No component is converted in this story except the three empty-art call sites (so the new rule has a user). Other call sites move in their own stories.
- Open point (decided in 12.8, noted here): DESIGN.md says widgets never use images, the prototype's empty states do (`K.empty({art, compact})`). This story ships the compact size only; 12.8 decides where art appears.

**Acceptance Criteria**

**Given** an empty Staff, Audit or Usage tab
**When** the harness renders it at 1280x800
**Then** the art is 144px high and its width follows the aspect ratio, and the empty block is shorter than 280px (G-26).

**Given** a `.card` containing a `.field` with a long label
**When** rendered inside a 400px column
**Then** the label wraps, nothing overflows the card, and the card has a border and no box-shadow. Test: `styles.test.ts` asserts the `.card` rule has `border` and no `box-shadow`.

**Given** a `.switch` input
**When** focused by keyboard and toggled with Space
**Then** the track shows the accent colour when checked, the focus ring is visible, and the control keeps its accessible name; axe reports zero violations.

**Given** a `.tabs` row wider than its container (Settings with the Admin sub-tabs at 1100px)
**When** rendered
**Then** it scrolls horizontally inside itself, the page does not, and the active tab is visible (`scrollIntoView` is not required; the active tab is first-fit).

**Given** `.btn.sm` and `.btn.block`
**When** applied
**Then** heights are 24px+padding and full width respectively, and neither changes `.btn` disabled styling (`styles.css:258` footer rule is untouched).

**Given** `styles.test.ts`
**When** it runs
**Then** it asserts the `/* 12.3 */` block defines `.card`, `.field`, `.empty img` (144px), `.set-col`, `.srow`, `.switch`, `.tabs` (overflow-x), and that no rule combines `border` with a raised `box-shadow` on `.card`.

**Given** the harness
**When** `node infra/ci/shots.mjs --only settings-staff` runs at 1100x700
**Then** overflow check (a) passes for the empty and the one-row states, and `report.json` lists no clipped-text failure on the tab row.
