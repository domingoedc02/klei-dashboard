# Story 12.9: Gallery layout matches the prototype

As a Staff member,
I want the Gallery filters, cards, empty states and bulk bar to look and behave like the approved prototype,
So that the grid is stable while I filter, select and delete.

**Assumptions**
- Audit row G-23. Prototype: `js/gallery.js:9` `.field` filters with an "All" option, `:25` **Upload photos** with an upload icon, `:27-29` Sort as a disabled `btn btn-secondary` with a clock icon and a ghost **Clear filters** after it only while a filter is active, `:30` card skeleton (square + two lines), `:31-33` bordered `card card-hover folder` with a 2x2 mosaic (always four tiles), `od-truncate` name and "sil · fab", `:34` no-match empty with a primary **Clear filters**, `:38-43` bulk bar always present with disabled buttons; `css/screens.css:81-82` `.filters`, `:90-93` `.bulk` and `.mosaic`.
- App today (`desktop/src/gallery/Gallery.tsx`): `:128-135` header and **Upload photos** without an icon, `:137` filters as label-wrapped selects, `:140` "All silhouettes", `:155` Clear filters is a `link`, `:156` Sort is a `sort-chip` span, `:161` eight bare `skeleton tall` tiles, `:167` and `:190` `<img art width={160}>`, `:170` empty CTA, `:175` the bulk bar renders only when `matching > 0`, so it appears and the grid jumps. `styles.css`: `:274` `.grid`, `:481` `.grid` repeat(4, minmax(0, 1fr)) inside a dead media query, `:275` `.skeleton.tall`.
- 11.7 decisions stay: paging stays (desktop only); Sort stays inert (prototype is `aria-disabled`); **Upload photos** stays gated by `PERM_UPLOAD_IMAGES`. The auto-fill fallback at 960px is dead (min window 1100); 12.2 deletes it, so the base rule is the 4-column `minmax(0, 1fr)` grid.
- Empty art: whole-view empties (empty Gallery, no matches) keep the line-art at the 12.3 size (144px, `width: auto`, no `width={160}`). They are whole views, not widgets, so DESIGN.md allows them.
- 11.7 stays `done`; this story corrects it.

**Acceptance Criteria**

**Given** the Gallery toolbar
**Then** each filter is a `.field` (12.3) whose label sits above a select, the first option reads "All" (not "All silhouettes"), **Upload photos** carries the upload `Icon`, and **Sort** is a disabled `btn secondary` with the clock icon (prototype `gallery.js:9,25,27-29`).
**Given** a filter is active
**Then** a ghost **Clear filters** button (not a `link`) follows Sort; with no filter it is absent.
Test: `Gallery.test.tsx` `it('renders filters as fields with an All option and a ghost Clear filters only when filtered')`; update the tests at `:55`, `:79`.

**Given** the Gallery is loading
**Then** it shows the toolbar plus eight 12.3 `.skeleton.card` tiles (image + two lines), same grid as the loaded state, so nothing shifts.
Test: `Gallery.test.tsx` `it('shows card skeletons with the grid layout while loading')`.

**Given** a gown folder card
**Then** it has a border and no shadow (`.card.card-hover`), a 2x2 mosaic that always renders four tiles (empty tiles are neutral blocks), a one-line name with ellipsis, and "sil · fab" below; a 40-character name does not widen the card.
Test: `Gallery.test.tsx` `it('renders four mosaic tiles and truncates a long name')` (asserts four tiles for a 1-photo gown and the truncate class); `styles.test.ts` `it('gallery grid is four minmax(0, 1fr) columns')`.

**Given** a filter that matches nothing
**Then** the no-match empty shows the line-art at 144px and a **primary** **Clear filters**; **Given** an empty library **Then** it shows the line-art and a primary **Upload photos** CTA (permission-gated).
Test: update `Gallery.test.tsx:95`, `:117`; assert no `width` attribute on the empty `<img>`.

**Given** any state with at least one gown, and the empty states
**Then** the bulk bar is always rendered with its buttons disabled until a card is selected (prototype `gallery.js:38-43`), so selecting a card does not move the grid.
Test: update `Gallery.test.tsx:130`, `:171` `it('keeps the bulk bar mounted and disabled with no selection')`.

**Given** `node infra/ci/shots.mjs --only gallery` and `--only gallery-empty` (the 12.1 screenshot command)
**When** run at 1100x700 and 1280x800
**Then** `report.json` shows no failure; the PNGs show four columns, no clipped names, a stable bulk bar, and match the prototype `gallery` screen.

**Tasks**

- `desktop/src/styles.css`: `.grid` as the single base rule, `.folder` card, `.mosaic` 2x2, bulk bar, remove the `:274`/`:481` duplicate (the media block is deleted by 12.2).
- Tests: `Gallery.test.tsx` (the five named above, plus the existing `:55`, `:79`, `:95`, `:117`, `:130`, `:171` updated), `styles.test.ts`.
- Docs: `docs/wireframe-inventory.md` gallery rows.
