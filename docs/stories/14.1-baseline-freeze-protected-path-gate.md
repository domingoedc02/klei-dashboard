# Story 14.1: Baseline freeze and protected-path gate

As the owner, I want the Tauri baseline recorded and "original unchanged" checked by one script, so that every later story can prove it left `desktop/`, `backend/`, `infra/`, `prototype/` and the existing workflows alone.

**Assumptions**
- Baseline is commit `51949da2a0f8347c5f1f56fc5d87d8ada6e60643` ("13.8: Upload Review: select, Move, Merge, Split"). It stays the migration baseline even if `main` moves.
- Work happens on branch `electron-migration` cut from that SHA. `develop` already holds the same code.
- Protected paths: `desktop`, `backend`, `infra`, `prototype`, `docs/api`, `docs/install-guide.md`, `docs/release-checklist.md`, `.github/workflows`. Allowed additions: `electron/`, `docs/`, and new `.github/workflows/electron*.yml`.
- This story creates files under `electron/` only.

**Acceptance Criteria**

**Given** the baseline SHA
**When** `electron/BASELINE.md` is written
**Then** it records the SHA, its subject line, the protected-path list, the nine bridge commands and their source, and the exact gate commands below.

**Given** a clean checkout of `electron-migration`
**When** `node electron/scripts/protected-paths.mjs` runs
**Then** it exits 0 and prints "protected paths unchanged".

**Given** a changed, deleted or renamed tracked file under a protected path, in the working tree or in committed history after the baseline
**When** the script runs
**Then** it exits 1 and names each offending path with its status letter.

**Given** a file added under a protected path
**When** the script runs
**Then** it exits 1 unless the path matches `.github/workflows/electron*.yml` and the status is `A` (committed) or `??` (untracked).

**Given** an untracked file anywhere under `desktop`, `backend`, `infra`, `prototype` or `docs/api`
**When** the script runs in working-tree mode
**Then** it exits 1 (ignored files such as `node_modules` and `dist` do not count).

**Given** the script is imported by a test
**When** the test feeds it recorded `git` output for a clean, a modified, an added-allowed and an added-forbidden case
**Then** each case returns the documented exit code without running `git`.

**Tasks**
- `electron/BASELINE.md`: record the baseline, path lists and gate commands.
- `electron/scripts/protected-paths.mjs`: run `git diff --name-status 51949da2a0f8347c5f1f56fc5d87d8ada6e60643 -- <protected paths>` (committed and working tree) and `git status --porcelain --untracked-files=all -- <protected paths>`; apply the allow rule; exit 0 or 1. Export a pure `evaluate(diffText, statusText)` for tests.
- `electron/test/protected-paths.test.ts`: the four cases above plus rename and delete.
- Record the manual form of the gate in `BASELINE.md`: `git diff --exit-code 51949da2a0f8347c5f1f56fc5d87d8ada6e60643 -- desktop backend infra prototype docs/api docs/install-guide.md docs/release-checklist.md .github/workflows` and `git status --porcelain --untracked-files=all -- desktop backend infra prototype docs/api .github/workflows`, accepting only `?? .github/workflows/electron*.yml`.

**Dev notes**
- A committed new `electron*.yml` shows as `A` in `git diff 51949da… -- .github/workflows`, so the plain `git diff --exit-code` form fails once the file is committed. The script therefore reads `--name-status` and allows only `A` on that name pattern, and it is the gate every other story cites. The plain form is valid only while no `electron*.yml` is committed.
- Pure ESM with no dependency; `git` is the only tool. Do not read or write any file under a protected path.
- Reference only: `docs/prd.md` §13 MFR-1; `docs/architecture.md` §13.1; spine AD-22.

**Testing**
- Run `electron/test/protected-paths.test.ts` against recorded `git` output only. For an end-to-end run, use a throwaway clone under `electron/.tmp/` (`git clone` of the repository, edit inside the clone, delete the clone); never edit, stage or restore a file under a protected path in the working repository.
- Not run in this documentation task.

**Prototype unchanged check**
- This story is the gate. Require the manual gate commands in `BASELINE.md` to return empty output (plus the allowed `electron*.yml` untracked entries) before the story closes.
- No renderer, Rust, backend or prototype file is read for modification; no screenshot comparison is needed because no UI is touched.
