# Story 1.8: App frame and shared UI

As a signed-in User,
I want the app shell with sidebar, top bar and the shared states,
So that every later screen drops into one consistent frame and never loses work when the connection drops.

**Assumptions**
- Pure front-end story over `GET /me`; no new backend table.
- Sidebar items appear only if the Permission exists in `/me` (A-UX7); screens are placeholders until their epic.
- The wireframe's role toggle and "View as" are not built.

**Acceptance Criteria**

**Given** a signed-in Admin
**When** the shell loads
**Then** it shows the framed sheet: sidebar 240 (Dashboard, AI Upload, Gallery, Inquiries, Settings), top bar 48 with the text wordmark "Klei Bridal", search slot, bell slot and profile menu (name, role, **Profile settings**, **Sign out**).

**Given** `/me` permissions of a default Viewer (`PERM_VIEW_GALLERY` only)
**When** the shell loads
**Then** Dashboard and Gallery show; Inquiries, AI Upload and the Assistant button are absent (Gallery also drops from the sidebar when a Role lacks `PERM_VIEW_GALLERY`), and a direct route to a forbidden screen shows "You don't have access" after a 403.

**Given** the toast stack, dialog host and drawer host
**When** three toasts are raised and a fourth follows
**Then** at most 3 show, errors persist until dismissed, one dialog opens at a time and the drawer slides in at 400.

**Given** any request failure of class network error, 10 s timeout, 502 or 503
**When** it happens
**Then** the banner "Offline. Reconnecting…" shows, `GET /health/ready` is called every 5 s, the banner clears with the toast "Back online", and Send-type actions are disabled while offline (NFR-3).

**Given** `set_dirty(true)`
**When** called
**Then** the shell records dirty state used later to block update install.

**Given** the keyboard
**When** `/` or Cmd/Ctrl+K is pressed outside an input
**Then** the search slot focuses; Esc closes an open menu, then dialog, then drawer.

**Given** `tokens.css`, Inter and IBM Plex Mono
**When** the shell renders
**Then** it uses the generated tokens, bundled fonts, a 2px `#0063bf` focus ring with 2px offset, minimum window 1100x700, and Vitest axe-core finds no serious issue.

**Tasks**
- Layout components, router, `usePermissions`, toast, dialog, drawer, banner, skeleton, error block, forbidden view, empty-state assets copied into `desktop/src/assets/empty/` (UX-DR10).
- Connection monitor in the Rust shell (health ping) and React banner.
- Component tests and axe-core checks.

**Checks**
- `cd desktop && npm test && (cd src-tauri && cargo test)`
- `cd backend && ./mvnw verify` (unchanged, must stay green)
- `docker compose -f infra/docker-compose.yml --profile dev up -d --wait && infra/ci/smoke.sh`
- NFR-1: no content cached on disk (Rust test from 1.7 still passes).
