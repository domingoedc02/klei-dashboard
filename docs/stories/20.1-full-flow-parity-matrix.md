# Story 20.1: Full-flow parity matrix run

As the reviewer, I want every screen state and every native flow compared between the Tauri app and the Electron preview on each OS, so that "no visual or functional regression" is recorded evidence.

**Assumptions**
- Visual side: the 14.2 harness, with the Electron side switched on, over every `SCREENS` entry that has a `desk` driver, at 1440×900 plus native 1280×800 and 1100×700.
- Native side: a scripted-plus-manual checklist run against the compose stack, on a real Tauri build and a real Electron package, on macOS, Windows and Linux.
- The two apps are run one after the other on the same machine and data.

**Acceptance Criteria**

**Given** the visual matrix
**When** `compare` runs on baseline vs Electron outputs
**Then** the report lists zero missing states, zero geometry findings and zero pixel differences above the tolerance fixed in the report header (default: zero); every difference has a written explanation and a PASS, CONCERNS or FAIL.

**Given** the native checklist
**When** run on each OS
**Then** a row exists, with result and evidence, for each of: sign-in (loopback), refresh after expiry, sign-out, "Continue without saving", photo upload (dialog), drag-and-drop upload, avatar, reply attachment, Gown archive export (save dialog, cancel, partial removal), thumbnails and `klei-img`, clipboard copy, `execCommand('insertText')`, `beforeunload` guard, dirty-work guard on the Update button, manual update check, hash routing and reload, window sizes, keyboard focus order.

**Given** the matrix
**When** a row is not run
**Then** it is marked NOT RUN with a reason; the epic gate treats NOT RUN as not PASS.

**Given** the evidence folder
**When** stored
**Then** it lives under `electron/parity-out/` and `docs/planning-artifacts/electron-migration/evidence/`; nothing is written under `docs/planning-artifacts/ui-parity/`.

**Tasks**
- Switch on `electron/test/parity/electron-side.mjs` and extend the mock API as needed.
- `docs/planning-artifacts/electron-migration/evidence/parity-matrix.md`: the table (row, OS, Tauri result, Electron result, evidence, verdict).
- `docs/planning-artifacts/electron-migration/evidence/parity-report.md`: summary and verdict per OS.
