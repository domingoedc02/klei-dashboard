# Story 13.16: Parity sign-off sweep

As the lead,
I want every screen and state re-captured, every audit row closed, and a keyboard pass,
So that the UI is declared in parity on evidence, not on a read.

**Assumptions**
- Runs last. Nothing new is built unless the sweep finds a regression; those are logged as new audit rows with the next free ID and fixed here.
- Window sizes: parity is judged at 1440x900. The minimum window (1100x700) is only sanity-checked for no overlap, no page-level horizontal scroll and no unreachable primary action.
- The design handoff's 360 to 1920 viewport matrix is for responsive web exports; the desktop app is a fixed desktop window, so it is not applicable (recorded as a decision, not skipped silently).

**Acceptance Criteria**

**Given** all stories 13.2 to 13.15 are done
**When** `cd desktop && npm run shots && npm run shots:diff` runs
**Then** every screen and state has a pair in `ui-parity/{prototype,desktop}/`, `report.json` lists no `pending`, and `geometry.json` has no desktop finding of the kinds named in the common gate

**Given** `docs/planning-artifacts/ui-parity/audit.md`
**When** it is read
**Then** all 182 rows are `closed` or `accepted deviation`, none `open`; every `accepted deviation` names its decision or reason

**Given** the lead's visual read of every pair
**When** the sweep finishes
**Then** the Dev record lists each pair as `match` or with its accepted fixture-only noise

**Given** a keyboard-only user
**When** they tab through Review, Gallery, Inquiries composer and Settings
**Then** focus is visible, order follows the layout, Esc closes menus and dialogs, and `axe.run` is clean on those screens

**Given** the window is 1100x700
**When** the key screens are captured
**Then** no overlap, no page-level horizontal scroll, and Save, Send, Confirm and Cancel are reachable

**Given** the full gates
**When** `npm test`, `npm run types:check`, `npm run build` run in `desktop/`
**Then** they pass, and `git diff --stat` shows no change under `backend/`

**Tasks**
- Re-run the full capture; read all montages; fix regressions as new rows.
- Close the audit table and update `docs/epics/epics.md` status for Epic 13.
- Write the sign-off note in this story's Dev record: pairs checked, rows closed, accepted deviations.

**Checks**
- `cd desktop && npm test && npm run types:check && npm run build`
- `cd desktop && node scripts/capture.mjs --side desktop` (desktop-only recapture, about 10 s per screen), then `npm run shots:diff`
- Read `docs/planning-artifacts/ui-parity/geometry.json` for this story's screens: desktop findings must be empty (see the geometry AC).
- Before the commit: `npm run shots` (both sides) once, so the prototype pairs are fresh.
- `git diff --stat` shows no change under `backend/` (this epic changes no API contract).
