# Story 11.1: Design tokens, type scale and icons

As a Staff member,
I want the desktop app and the sign-in pages to look like the approved prototype,
So that every screen shares one type scale, one icon set and the same depth.

**Assumptions**
- The prototype (`prototype/v0.1.0`) wins over `docs/ux-spec.md` §1 and §2. `DESIGN.md` was revised on 2026-11-10 to match the prototype; `ux-spec.md` is stale and is corrected in this story.
- Tokens live in two places and both change: `backend/app/src/main/resources/static/tokens.css` (shared with the Auth Web pages) and `desktop/src/styles.css`. A value is changed in `tokens.css` first.
- First task is to confirm the gap rows marked "verify": the body and heading values in `tokens.css` (`--type-*`), and the shadow use in `styles.css` (`.drawer`, `.menu`, `.dialog`).
- Prototype values: body 16 px / 1.5, `--text-sm` 14 px for secondary text, h1 26 px / 700 / tracking -0.033em, pane h1 20 px; radii sm 4, md 8, lg 12, pill; `--elev-raised` on menus, search popup, toast, dialog and drawer; spacing 4 to 48; pills blue `#f2f9ff` on `#097fe8`, green `#e8faf0` on `#14802a`, gray, warn `#fff3e8` on `#b34700`; avatar dark circle 32 px (lg 72, sm 24); `.skel` shimmer.
- `[ASSUMPTION]` Two prototype values fail WCAG AA contrast and are **kept at the desktop value**: meta text stays `#716c66` (prototype `#a39e98`) and the focus ring stays `#0063bf` 2 px (prototype `#097fe8` plus 3 px glow). Accessibility is not cut. The deviation is logged in the Dev record.
- `[ASSUMPTION]` Skeleton shimmer respects `prefers-reduced-motion` (static block then).
- Icons: one inline SVG set (stroke 1.75, 20 px, `currentColor`) in a single `desktop/src/shell/icons.tsx`, copied from the prototype's `K.icon` paths (`prototype/v0.1.0/js/core.js`). No icon dependency is added. Decorative icons are `aria-hidden`; an icon-only button keeps its `aria-label`.
- Inter weight 700 (latin) is added next to 400, 500 and 600 in `static/fonts/` and loaded by both CSS files, so bold stops being synthesized. The mono font stays `ui-monospace, "SF Mono", Menlo, monospace`; `DESIGN.md` is corrected to say so (no font file is bundled for it).
- OPEN QUESTION (T-1): the body size of 16 px reflows every screen. Default: adopt it; Stories 11.2 to 11.11 re-check their own layouts.

**Acceptance Criteria**

**Given** `tokens.css`
**When** `desktop/src/styles.test.ts` parses it
**Then** body is 16 px / 1.5, h1 26 px / 700, radii are sm 4 / md 8 / lg 12, and an elevation token `--elev-raised` exists.

**Given** a menu, the search popup, a toast, a dialog or the drawer
**When** rendered
**Then** each uses `--elev-raised` and no other box-shadow (checked by a test that scans `styles.css` selectors `.menu`, `.search-pop`, `.toast`, `.dialog`, `.drawer`).

**Given** the Inter files
**When** the page loads
**Then** a 700 weight file is served, and `font-weight: 700` text does not fall back (checked in `tokens.css` `@font-face`).

**Given** `desktop/src/shell/icons.tsx`
**When** `icons.test.tsx` renders every exported icon
**Then** each is an `svg` with `aria-hidden="true"` and `currentColor`, and the set contains at least: dashboard, upload, gallery, inquiries, settings, search, bell, spark, check, close, alert, info, chevron, upload-cloud, trash, download, edit, mail, plus.

**Given** the pill variants
**When** `Pill` renders `info`, `pos`, `neutral` and `warn`
**Then** colours match the prototype palette in this story's assumptions.

**Given** the skeleton
**When** motion is allowed
**Then** it shimmers; with `prefers-reduced-motion: reduce` it is a static block.

**Given** every colour pair used for text
**When** `axe` runs on Dashboard, Gallery, Inquiries and Settings in `App.test.tsx`
**Then** zero `color-contrast` violations.

**Given** `docs/ux-spec.md` §1 and §2
**When** the story closes
**Then** they state the prototype values (no framed-sheet, 64 px top bar, radii 4/8/12, elevation) and `DESIGN.md` is aligned; a short "deviations kept for accessibility" list names the two values above.
