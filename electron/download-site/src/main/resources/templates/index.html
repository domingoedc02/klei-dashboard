First launch

  • macOS: open the disk image, drag the app to Applications, open it. If macOS says it cannot verify the app, choose Done, then open System Settings, Privacy & Security and choose Open Anyway. On macOS 14 or earlier, right-click the app in Finder and choose Open instead.
  • Windows 11: run the installer. If a blue "Windows protected your PC" window appears, choose More info, then Run anyway.
  • Ubuntu 24.04: for the AppImage, run chmod +x on the file, then open it. For the .deb, install it with your software installer.
